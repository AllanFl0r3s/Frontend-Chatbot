# Visión del Proyecto: Chatbot Istmania

## 1. Visión del producto

Desarrollar una plataforma conversacional inteligente para Distribuidora Istmania S.A. de C.V. que permita al personal consultar información comercial y operativa de manera rápida, segura y eficiente.

El chatbot centraliza el acceso a información de inventarios, pedidos, ventas, proyecciones, notas de crédito y promociones, reduciendo la necesidad de realizar consultas manuales en diferentes sistemas y facilitando la toma de decisiones.

La solución busca mejorar la productividad del personal mediante respuestas automatizadas, disponibilidad de información y una experiencia de consulta intuitiva.

## 2. Problema

Actualmente, el personal de Istmania necesita consultar información comercial y operativa, como existencias de productos, pedidos, ventas y promociones, para realizar sus actividades diarias.

Cuando estas consultas requieren acceder a diferentes fuentes de información o depender de otros colaboradores, pueden generar tiempos de espera, interrupciones y dificultades para obtener información oportunamente.

Esto puede afectar la eficiencia operativa y retrasar la atención de solicitudes internas y de clientes.

### Problema principal

¿Cómo podemos facilitar al personal de Istmania el acceso oportuno y confiable a la información comercial y operativa, reduciendo el tiempo y el esfuerzo necesarios para realizar consultas frecuentes?

## 3. Evidencia del problema

La siguiente evidencia se basa en la documentación del proyecto y en las funcionalidades implementadas.

| Evidencia | Descripción |
|---|---|
| Diversidad de consultas | El sistema contempla consultas de stock, pedidos, ventas, proyecciones, notas de crédito y promociones. |
| Necesidad de información actualizada | El chatbot consulta información de bases de datos corporativas, incluyendo stock por centro y datos comerciales. |
| Consultas con múltiples filtros | Las ventas pueden consultarse por producto, vendedor o categoría y por diferentes períodos. |
| Necesidad de acceso sencillo | El usuario puede realizar consultas mediante mensajes escritos en una interfaz conversacional. |
| Automatización de consultas | El sistema permite obtener respuestas automáticas y estructuradas sobre información comercial y operativa. |

**Limitación de la evidencia:** Los documentos describen las funcionalidades y las pruebas realizadas, pero no incluyen mediciones cuantitativas del tiempo de consulta antes y después de implementar el chatbot. Por ello, la magnitud del problema y el ahorro de tiempo deberán validarse mediante pruebas con usuarios.

## 4. Lean Canvas

### Segmentos de clientes
- Personal de ventas.
- Personal de operaciones y logística.
- Personal administrativo que consulta información comercial.
- Supervisores y responsables de equipos comerciales.

### Problema
- Consultar información comercial y operativa puede requerir tiempo y múltiples pasos.
- El acceso a información de diferentes áreas puede depender de otros colaboradores o sistemas.
- Obtener información oportuna es importante para atender solicitudes y tomar decisiones.

### Propuesta única de valor
**Consulta la información comercial de Istmania de forma rápida y sencilla, desde un solo chatbot.**

### Solución
- Consulta conversacional de inventarios y stock por centro.
- Consulta de detalles de pedidos.
- Consulta de ventas por producto, vendedor y categoría.
- Consulta de proyecciones de venta.
- Consulta de notas de crédito y promociones.
- Autenticación y administración de usuarios según sus roles.

### Canales
- Aplicación web accesible desde computadora y dispositivos móviles.
- Interfaz conversacional del chatbot.
- Acceso interno para el personal autorizado.

### Fuentes de ingresos / valor para la empresa
El proyecto no contempla ingresos directos por comercialización del chatbot. Su valor esperado para Istmania consiste en:
- Reducción del tiempo dedicado a consultas.
- Mayor eficiencia del personal.
- Mejor acceso a información para la toma de decisiones.
- Optimización de procesos internos y atención al cliente.

### Estructura de costos
- Desarrollo y mantenimiento de la aplicación.
- Infraestructura y alojamiento del sistema.
- Acceso a bases de datos corporativas.
- Consumo de la API de inteligencia artificial.
- Conectividad y soporte técnico.

### Métricas clave
- Tiempo promedio para completar una consulta.
- Porcentaje de consultas respondidas correctamente.
- Porcentaje de consultas completadas sin asistencia adicional.
- Número de usuarios activos y consultas realizadas.
- Disponibilidad del sistema.

### Ventaja diferencial
Integración con las fuentes de información corporativas de Istmania y capacidad de consultar datos comerciales y operativos mediante lenguaje natural, en una plataforma diseñada para las necesidades internas de la empresa.

## 5. Hipótesis de validación

Las siguientes hipótesis deberán comprobarse mediante pruebas con usuarios reales. Los porcentajes y tiempos son objetivos propuestos, no resultados existentes.

| ID | Hipótesis | Método de validación | Criterio de éxito propuesto |
|---|---|---|---|
| H1 | El chatbot reduce el tiempo necesario para realizar consultas comerciales frecuentes. | Comparar el tiempo de consultas manuales con consultas realizadas mediante el chatbot. | Reducir al menos un 30% el tiempo promedio de consulta. |
| H2 | Los usuarios pueden obtener información confiable mediante el chatbot. | Comparar las respuestas del chatbot con los datos de las fuentes corporativas. | Al menos un 95% de respuestas correctas en una muestra de consultas de prueba. |
| H3 | La interfaz conversacional es fácil de utilizar para el personal. | Realizar pruebas de tareas con usuarios y recopilar sus comentarios. | Al menos un 80% de los usuarios completa las tareas sin ayuda. |
| H4 | La centralización de consultas disminuye la necesidad de recurrir a otros colaboradores para obtener información. | Registrar consultas que requieren asistencia adicional antes y después de utilizar el chatbot. | Reducir al menos un 20% las consultas que requieren asistencia adicional. |

## 6. Alcance del producto

### Incluido
- Inicio de sesión y control de acceso por roles.
- Consulta de stock y disponibilidad por centro.
- Consulta de detalles de pedidos.
- Consulta de ventas y proyecciones.
- Consulta de notas de crédito.
- Consulta de promociones.
- Administración de usuarios y perfil institucional.

### Fuera del alcance
- Sustituir los sistemas corporativos de origen.
- Modificar directamente los datos de las bases de datos comerciales externas.
- Reemplazar completamente la atención humana.
- Garantizar respuestas cuando las fuentes de información no estén disponibles.

## 7. Resultado esperado

Contar con una herramienta conversacional funcional, segura y fácil de utilizar que facilite el acceso a información comercial y operativa, reduzca el esfuerzo de las consultas frecuentes y contribuya a mejorar la eficiencia del personal de Istmania.
