
# Bitácora - Semana 2

Durante esta semana se organizaron las historias de usuario del proyecto Chatbot Istmania en GitHub. Se crearon 15 Issues con sus criterios de aceptación para tener más claro qué funcionalidades se deben desarrollar.

También se definieron dos etapas para el proyecto: una primera versión con las funciones principales y una segunda con funcionalidades adicionales.

Como siguiente paso, se continuará trabajando en las historias priorizadas para el MVP y se verificará que la aplicación esté disponible en producción.
