Bitácora de Desarrollo — Semana 1

Proyecto: Chatbot Istmania
Desarrollador: Allan Flores
Semana: 1
Período: [31-10-26] – [23-12-26]

1. Objetivo de la semana

Establecer las bases del proyecto Chatbot Istmania mediante la revisión de la documentación existente, la definición de la visión del producto y la preparación del repositorio para el desarrollo y seguimiento de futuras mejoras.

2. Actividades realizadas

Revisión del Manual de Usuario del Chatbot Istmania para identificar las funcionalidades disponibles.

Revisión del Manual Técnico para conocer la arquitectura, las tecnologías utilizadas y la integración con las bases de datos corporativas.

Análisis del documento de propuesta del proyecto para comprender sus objetivos, alcance y metodología de desarrollo.

Identificación del problema que busca resolver el chatbot y de los principales usuarios del sistema.

Elaboración del documento de visión del producto, incluyendo problema, evidencia, propuesta de valor y alcance.

Elaboración del Lean Canvas para estructurar la propuesta de valor y el modelo de solución.

Definición de hipótesis iniciales para validar la utilidad, facilidad de uso y eficiencia del chatbot.

Preparación de la estructura documental del repositorio.

3. Aprendizajes

Comprensión del propósito del chatbot como herramienta de consulta comercial y operativa.

Identificación de las funcionalidades principales: stock, pedidos, ventas, proyecciones, notas de crédito y promociones.

Comprensión de la importancia de validar las necesidades de los usuarios mediante pruebas y métricas.

Familiarización con el uso de Git y GitHub para documentar y controlar los cambios del proyecto.

4. Dificultades encontradas

Definir métricas cuantificables para evaluar el impacto del chatbot sin contar todavía con mediciones comparativas.

Organizar la documentación existente en una visión clara del producto.

Identificar hipótesis que puedan comprobarse mediante pruebas con usuarios.

5. Próximos pasos

Revisar y completar la documentación inicial del proyecto.

Validar las hipótesis con usuarios potenciales.

Definir las tareas técnicas prioritarias para las siguientes semanas.

Continuar con el desarrollo y las pruebas incrementales del chatbot.
